# 🐍 Classic Snake Game in Java

A lightweight 2D Snake game built using Java Swing and AWT graphics[cite: 4, 5]. It features real-time score tracking, responsive controls, and smooth game restarts[cite: 4].

**Developed by:** Swapnil Gaikwad[cite: 5]

---

## 🌟 Features

* **Live Scoreboard:** Shows your score continuously while playing[cite: 4].
* **Quick Restart:** Press **'R'** on the Game Over screen to start a new round[cite: 4].
* **Zero Dependencies:** Uses standard Java graphics—no external image files required[cite: 4].
* **Collision Detection:** Automatic detection for hitting walls or the snake's tail[cite: 4].

---

## 🎮 Controls

| Key | Action |
| :--- | :--- |
| **Arrow Keys** | Move Snake (Up, Down, Left, Right)[cite: 4] |
| **R** | Restart Game (when Game Over)[cite: 4] |
